## 1. 目标与边界

页面以“回答 → 看清关键问题 → 按建议重答”为核心，不生成长篇代写报告。面试只服务求职账号，保留三道主问题、每题最多一次追问；不包括语音、计时或联网检索。练习表现指数只用于个人练习比较，不代表招聘评价或录用结果。

新会话创建时固定 `interview-rubric-v2`。旧会话不删除、不重算、不改版，也不出现在新版列表、面试趋势和面试下一步建议中。旧链接给出保留说明和新练习入口；已入队的旧任务继续按原规则执行。简历、匹配报告、用量和审计口径不变。

## 2. 实现职责

当前实现以实际源码为准，不假设存在独立的 InterviewService 或 LangGraph 状态机。

| 组件 | 职责 |
| --- | --- |
| `api.py` | 账号限定访问、开场/回答/结束、重答提交与查询、删除控制 |
| `interview_rubric.py` | 五维规则、严格引用校验、结构化提纲、确定性聚合与对照 |
| `model_provider.py` | 本地/OpenAI 适配、冻结题型、版本路由、一次自动修复和消耗累计 |
| `services.py` | 幂等任务、执行代次、预算、用量和安全日志 |
| `worker.py` | 与内联共用执行契约，处理四种面试任务 |
| `InterviewView.vue` / `InterviewFeedback.vue` | 单列回答流程、紧凑反馈、折叠历史及弹窗重答 |

## 3. 题型与可信评价

开场为每道主问题保存 `question_kind` 和岗位依据；追问继承父题型。反馈阶段不临时改判。

| 题型 | 具体度与个人贡献 | 结果证据 | STAR |
| --- | --- | --- | --- |
| 经历题 experience | 真实场景、本人职责、判断与实际行动 | 实际结果、指标或核验依据 | 单独折叠诊断 |
| 判断题 reasoning | 问题理解、判断依据、方案比较与取舍 | 推论及验证方法，不要求历史业绩 | 不展示 |
| 情景题 scenario | 假设、约束、角色责任与拟议行动 | 风险、验证及监控方案 | 不展示 |

主问题返回 `interview-feedback-v5`。五维沿用回答切题度、事实具体度、个人贡献清晰度、结果证据力度、表达结构与清晰度，各自为 strong/partial/missing。非缺失等级必须引用本轮回答的真实片段：先逐字校验完整引用，再截短展示。非法等级、缺项或引用不匹配最多自动修复一次；仍无效则任务失败，回答已保存，不能记为用户信息不足、零分或推进下一题。

追问仅反馈“补充依据、仍需澄清”，可结合主回答和本轮回答；主回答引用明确标记来源，不重复五维打分、不入指数。

专业核查与方案权衡独立展示最多三条，每条含本轮原文论断、疑点和核验动作。不联网、不伪造文献、不保证权威事实校验，也不因术语多而默认正确；不确定项标为需核实，不入指数。

建议用“请补充／请说明／请核实”，不新增未经确认的第一人称经历、参数或成果。重答提纲只包含已逐字核对的原文片段和按题型生成的待补充槽位，不提供虚构事实长模板。

## 4. 整场指数与独立重答

`interview-summary-v3` 的指数由服务端确定性计算：strong=100、partial=50、missing=0，直接平均三道主问题的十五项等级，再取整展示。五维分项分别平均三题；不可二次平均已取整的分项。只有完整完成、三题评价有效且规则一致才生成指数。提前结束、追问和独立重答都不入数值。

完整完成或提前结束后，每道已回答主问题可领取一次免费重答。训练存在独立 `interview_practices` 表；不覆盖正式回答、原反馈、总结、指数或会话状态。只有成功生成反馈才消耗机会；失败只能重试同一任务和同一份回答，成功后不可再次提交或覆盖。

对照逐维显示提升、不变、下降和对应原文依据。无有效基线明确显示无法比较，不近似换算旧评价、不虚构改善。

## 5. 保存、并发与恢复

- 正式回答一次提交后不可覆盖；回答与开场的公共请求格式不变。
- 重答需要幂等键；同键同正文返回原记录，同键不同正文冲突。数据库唯一约束限制每场每主题一条训练，账号写入通道与会话行锁串行化并发领取。
- 训练任务 `interview_practice` 复用任务查询、失败重试、执行代次及 outbox，同时支持内联和 Worker。会话当前任务排除训练任务；训练失败只改变训练记录。
- 刷新从详情恢复已提交训练；前端轮询和异步返回按会话及操作代次隔离。关闭弹窗不丢失已提交记录，同页未提交重答草稿按场次/问题隔离。
- 等待用户回答不占 Worker。失败保留原任务入口、请求 ID 和已保存回答。

## 6. 成本、删除与安全

开场成功结算一场面试；后续正式反馈、结束与免费重答不再次预留/结算用户次数。免费训练仍正常计模型成本，受全站预算、请求限流和账号任务并发限制。

预算预留覆盖最多两次反馈调用，最后一轮另覆盖总结调用。当前新反馈单次输出上限 6000 token，开场/总结 3000；输入按 UTF-8 字节保守估算并预留指令开销。修复和后续总结失败均累计已知 token；消耗未知时保留预算未知持有，不当作零成本。

训练读取、重试及保存校验账号状态、同账号会话/问题/原回答和来源资料。简历、报告、岗位、会话删除将训练隐藏并取消相关任务；保存时重新校验，删除后的迟到 Worker 不能回写或重试复活。完整性巡检覆盖训练及全部逻辑引用。

日志仅记录请求、账号、会话、问题、训练、任务、实际规则版本、阶段、异常类型；不记录问题、回答、简历、JD 或模型正文。任务返回安全资源引用，不承载私有正文。

## 7. 页面与验收

单列展示岗位、进度、当前问题、回答和本题反馈；不提前铺开未答题。反馈默认两句结论、五维紧凑状态和最多两条动作，点击展开理由/短原文；经历题 STAR 和提纲折叠。已答题历史默认折叠，会话历史及重答在弹窗展示，手机对照上下排列。

验收覆盖三类题型、引用和结构失败、禁止虚构、专业判断、追问排除、三题等权、提前结束、一次免费资格、并发/幂等、预算拒绝、失败恢复、账号隔离、删除与迟到 Worker。迁移和演练流程见上线说明。
