# Purslyx 部署说明

当前推荐的部署方式是：

- OpenResty、PostgreSQL、Redis 运行在 Debian 宿主机；
- FastAPI、Vue 构建产物和 Worker 使用 Docker 镜像；
- `purslyx-api1` / `purslyx-api2` 双槽位通过 OpenResty upstream 原子切换实现滚动发布和回滚。

完整步骤请阅读：[Debian 单机部署](Debian单机部署.md)。

仓库中的部署文件：

- [`compose.yaml`](../../../compose.yaml)
- [`infra/docker/Dockerfile`](../../../infra/docker/Dockerfile)
- [`scripts/release.sh`](../../../scripts/release.sh)
- [`scripts/worker.py`](../../../scripts/worker.py)
- [`infra/openresty/purslyx.conf`](../../../infra/openresty/purslyx.conf)

本地 201 PostgreSQL 开发环境仍使用：[201 环境部署约定](201环境部署.md)。

## 官网一键安装浏览器脚本

部署完成后，官网首页的“浏览器助手”区域会提供 Tampermonkey 安装入口，也可以直接访问：

```text
https://purslyx.com/purslyx-job-capture.user.js
```

用户首次使用时按以下顺序操作：

1. 安装 Chrome/Edge 的 [Tampermonkey](https://www.tampermonkey.net/)。
2. 登录 `https://purslyx.com`，在首页点击“一键安装浏览器脚本”，在 Tampermonkey 页面确认安装。
3. 打开 BOSS 直聘或猎聘的岗位详情页，脚本会在页面右下角显示 Purslyx 面板。
4. 点击“同步 Purslyx”。脚本会打开一次性同步窗口；如果官网尚未登录，先登录后再回到岗位页重新点击同步。
5. 同步成功后，脚本会读取当前岗位详情并直接写入 Purslyx 匹配池；需要分析时，在匹配池点击“匹配”再选择简历和岗位期望。

脚本支持自动更新，官网发布新版本后 Tampermonkey 会按脚本头部的 `@updateURL` 检查更新。脚本不会自动投递、代聊或提交简历；岗位数据先进入待匹配状态，缺失字段按页面实际情况保留为待确认。

本地开发时，修改 `src/userscript/purslyx-job-capture.user.js` 中的 `API_ORIGIN` 和 `PRODUCT_ORIGIN` 为本地前端/API 地址，并在 Tampermonkey 中重新安装本地脚本；生产安装版保持为 `https://purslyx.com`。
