# 201 环境部署约定

Purslyx 本地开发只使用同目录《本地开发环境.md》中的 `10.10.10.201` PostgreSQL。该文件被 Git 忽略，是连接账号和密码的唯一来源；应用不支持 SQLite，也不连接其他主机。

## 首次准备

```bash
uv venv .venv
uv pip install -e '.[test]'
```

本机需要 Python 3.12、Node.js 和 npm。前端依赖由 `src/web/package-lock.json` 锁定。

## 启动产品

```bash
scripts/start_201_local.sh
```

脚本按以下顺序执行：

1. 从《本地开发环境.md》读取 PostgreSQL 连接信息，只把密码注入当前进程；
2. 校验数据库主机固定为 `10.10.10.201`；
3. 必要时执行 `npm ci`，随后运行前端类型检查和 Vite 生产构建；
4. 执行 Alembic 向前迁移和幂等种子写入；
5. 在 `127.0.0.1:8001` 启动 FastAPI。

浏览器入口为 <http://127.0.0.1:8001/>。`GET /health` 必须返回 `environment=201` 和 `database.backend=postgresql`。

## 独立 Worker 模式

```bash
# 终端 A
PURSLYX_EXECUTION_MODE=worker scripts/start_201_local.sh

# 终端 B
PYTHONPATH=src .venv/bin/python scripts/worker_201.py
```

HTTP 进程只提交任务和 PostgreSQL outbox，Worker 处理解析、分析、改写、PDF、面试反馈／总结和日志导出。

## 提交前验收

```bash
.venv/bin/ruff check src tests scripts migrations
PYTHONPATH=src .venv/bin/pytest -q

npm --prefix src/web run typecheck
npm --prefix src/web test -- --run
npm --prefix src/web run build

PYTHONPATH=src .venv/bin/python scripts/migrate_201.py verify
PURSLYX_BASE_URL=http://127.0.0.1:8001 PYTHONPATH=src .venv/bin/python scripts/smoke_201.py
PURSLYX_BASE_URL=http://127.0.0.1:8001 PYTHONPATH=src .venv/bin/python scripts/smoke_admin_201.py
PURSLYX_BASE_URL=http://127.0.0.1:8001 PYTHONPATH=src .venv/bin/python scripts/smoke_concurrency_201.py
PYTHONPATH=src .venv/bin/python scripts/integrity_scan_201.py
PURSLYX_BASE_URL=http://127.0.0.1:8001 node scripts/e2e_web_201.mjs
```

Worker 验收应另启一个临时 8002 HTTP 进程，避免改变 8001 的运行模式：

```bash
PURSLYX_PORT=8002 PURSLYX_EXECUTION_MODE=worker scripts/start_201_local.sh
PURSLYX_BASE_URL=http://127.0.0.1:8002 PYTHONPATH=src .venv/bin/python scripts/smoke_worker_201.py
PURSLYX_BASE_URL=http://127.0.0.1:8002 PYTHONPATH=src .venv/bin/python scripts/smoke_worker_recovery_201.py
```

`smoke_worker_201.py` 还会验证面试反馈和总结的失败重试，以及删除期间迟到 Worker 不会复活资源。

管理员日志导出可额外运行 `scripts/smoke_log_export_201.py`。管理员身份必须由调用方显式注入；脚本没有凭据时安全跳过。

任何命令和日志都不得输出《本地开发环境.md》中的密码，也不得把密码拼入 `DATABASE_URL`。
