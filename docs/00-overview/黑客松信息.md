## 选一个赛题，把它做完

## 赛题一 | 个人网站

让别人快速认识你。用真实经历、项目和思考，搭建一个属于自己的展示空间。

最低完成：网站可以访问，包含自我介绍、能力或经历、至少一个真实案例和联系入口；手机端主要内容可读。

评优重点：有自己的内容和风格，案例能证明能力，而不是只换模板文字和配色。

## 赛题二 | 求职 Agent / skill

拆JD、改简历、练面试。完成轻量的求职全流程，并选择其中一个环节重点打磨。

最低完成：岗位要求拆解、基于事实的简历建议、至少3个针对性面试问题，以及一轮回答反馈。

评优重点：建议真正有帮助；不编造经历，不靠堆砌漂亮话制造“看起来优化了”的假象。

## 赛题三 | DeepSeek Harness 插件开发

给AI助手增加一项真本领。从主办方提供的固定版本和插件模板出发，开发一个有实际用途的工具或能力。

最低完成：插件能够安装、加载和调用；提交源码、运行说明、一个成功案例和一个异常输入案例。

评优重点：解决真实问题，使用顺手，功能确实改变任务结果，而不是只让输出看起来更漂亮。

## 参与规则

- 个人或1-3人组队。每人只能加入一队，每队提交一件主作品。

- 每队选择一个主赛道。可以融合其他赛道能力，但只参加一个赛道排名。

- 允许使用AI、模板、开源项目和已有项目。需要注明来源、项目起点和活动期间新增的内容。

- 提交真实作品。提供体验方式或可复现材料，以及2-3分钟真实操作视频。

- 保护个人信息。简历使用虚构或脱敏材料，不公开密钥、地址或他人隐私。

- 截止后冻结功能。评审阶段只允许恢复截止前已有功能，不得新增评分功能。
