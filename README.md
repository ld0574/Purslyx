# Purslyx

<img src="docs/00-overview/brand/logo.png" alt="Purslyx：提着公文包的猞猁" width="180" />

> **AI that hunts your next opportunity.**

Purslyx 是面向求职者与招聘方的 AI 助手，提供有依据的岗位匹配、简历改写、岗位版简历、模拟面试和招聘分析。
